# MarketScope v5.7.1 — Total Profit Sorting

This update adds **Total Profit ($)** as a card-sort option.

- The sort uses the dollar amount entered in **Investment amount ($)**.
- It compounds the same completed calendar-year returns used by each card.
- If **Include current YTD** is enabled, YTD is included in the profit calculation before sorting.
- **High → Low** ranks the largest historical dollar profit first.
- **Low → High** ranks the smallest/most negative historical dollar result first.
- Instruments without enough completed annual-return history are placed last.

All v5.7 annual-return, 213-ETF, Nasdaq >$100B stock, signal, persistence, and daily-refresh behavior is preserved.
