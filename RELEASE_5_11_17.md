# MarketScope 5.11.17

- Economic calendar now requests United States (country 5) only, retaining weekly three-star events and Eastern announcement times. The complete provider frame receives a dark color treatment; dark source text prevents the prior pale-on-white readability problem. Provider attribution remains visible.
- None cadence runs once as Performance. Results, saved summaries, PDFs and Excel avoid RB/NR labels and redundant comparison tables. Existing None-cadence snapshots receive the same presentation without changing stored calculations.
- Every PDF profit table has an explicit Date / period column. Profit graphs include intermediate date labels as well as start/end dates. Report headings retain the actual simulation date range.
- All previous cumulative features remain included. No new environment variables. Preserve live data when deploying. Not deployed by this release.
