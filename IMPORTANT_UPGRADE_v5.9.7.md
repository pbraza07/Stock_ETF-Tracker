# Important upgrade notes - v5.9.7

This release changes only the saved Portfolio Split Simulator PDF presentation/calculation layer; it does not change the 213-ETF universe or market snapshot schema. Existing saved simulations can be downloaded again under v5.9.7 and will receive the new combined first-page layout because the portfolio-level metrics are derived from each saved instrument allocation and performance record.

The first PDF page is now landscape A4 so all requested combined timeframe columns remain readable: 1D, 1M, 3M, 6M, YTD, 2025, 2024, 2023, 2022, 2021, 2020, 2019, 2018, 2017, and 2016.
