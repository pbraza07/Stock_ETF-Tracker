# MarketScope v5.9.21 — Single Comparison Selector + PDF Current Price/Targets

Authoritative parent: MarketScope v5.9.20.

## Changes
- Removed the separate comparison search box and Yahoo-result chooser from the Comparison tab.
- Removed Card View and Table View controls that directly changed comparison membership.
- The existing `Stocks & ETFs to compare (unlimited selection)` multiselect is the only comparison membership input.
- The selector remains searchable and displays symbol, name, type and sector.
- Portfolio PDF instrument snapshots now include current price plus analyst low/average/high targets.
- Mobile PDF sharing and Back to MarketScope remain enabled through `static/pdf_viewer.html`.
