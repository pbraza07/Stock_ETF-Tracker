# MarketScope v5.4.1 — Universe File Recovery Fix

This build fixes the Render startup error:

`FileNotFoundError: No market universe is available.`

## What changed

1. The user-provided `default_universe.csv` and `default_universe.bootstrap.csv` are included under `data/`.
2. Both CSVs were normalized to UTF-8 so Python/pandas can read them reliably on Render/Linux.
3. `universe.py` now accepts UTF-8, UTF-8 BOM, Windows-1252, and Latin-1 universe CSVs.
4. If files are accidentally uploaded to the repository root, MarketScope also checks root-level `default_universe.csv` and `default_universe.bootstrap.csv` as recovery locations.
5. Bootstrap stocks with missing market-cap values are allowed only as an emergency startup fallback until the Nasdaq refresh regenerates the strict >$100B universe.
6. The live `market_snapshot.csv` is still not bundled, so this recovery build does not overwrite durable return/signal data generated by the server-side refresh.

## Deployment

Upload all files in this package over the existing GitHub repository. Make sure the `data/` directory is preserved exactly, including:

- `data/default_universe.csv`
- `data/default_universe.bootstrap.csv`
- `data/etf_allowlist.csv`

Render should then redeploy automatically. After the app opens, run the GitHub daily refresh workflow once if you want the latest Nasdaq universe and market snapshot immediately.
