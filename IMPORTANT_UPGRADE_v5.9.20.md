# MarketScope v5.9.20 — Organized Tabs + Enhanced Comparison Search

Authoritative source baseline: **MarketScope v5.9.18**, carried forward through the verified v5.9.19 server-PDF/mobile-share release.

## Changes

1. **Top workspace tabs**
   - Market Navigator
   - Portfolio Simulator
   - Stock & ETF Comparison
   - Alerts & Help

2. **Market Navigator grouping**
   - Quick Filters
   - Manual refresh/status
   - Investment Simulator
   - Card/Table display mode
   - Market Navigator cards/charts/search/sorting

3. **Portfolio workspace**
   - Build Simulation internal tab
   - Saved / Manage internal tab
   - Existing server PDF persistence, GitHub recovery, phone Open/Share PDF, Download PDF, and Delete functionality preserved

4. **Enhanced Stock & ETF Comparison search**
   - Searches symbol, name, type, sector, industry and analyst rating across the tracked universe
   - Search results can be multi-selected and added directly to comparison
   - Optional Yahoo Finance lookup discovers stocks/ETFs not already tracked
   - A discovered instrument can be loaded, persisted, added to MarketScope, and immediately added to comparison

5. **Compact PDF/GitHub setup help**
   - Small popover button near the top of the app
   - Contains the one-time `MARKETSCOPE_GITHUB_TOKEN` setup instructions
   - Shows configured/not-configured status without ever displaying the token value

6. **Mobile navigation**
   - Top tab bar is horizontally scrollable on narrow phones rather than compressing labels into unreadable controls.
