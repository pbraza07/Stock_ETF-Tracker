# MarketScope Return Methodology — v5.5

MarketScope uses adjusted historical market prices so stock returns include split/dividend adjustment where provided by the data source.

- 1D
- 1M
- 3M
- 6M
- YTD

## Annualized average returns (CAGR)
- 1Y Avg
- 2Y Avg
- 3Y Avg
- 4Y Avg
- 5Y Avg
- 6Y Avg
- 7Y Avg
- 8Y Avg
- 9Y Avg
- 10Y Avg

For a requested N-year CAGR, MarketScope uses an adjusted historical price near the N-year calendar anchor and the latest adjusted/live price. It only reports the horizon when sufficient history exists; it does not fabricate missing coverage.

Stocks do not have NAV. ETF NAV is not presented as stock return data. The performance navigator uses adjusted market total-return history for the displayed return metrics.
