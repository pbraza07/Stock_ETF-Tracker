# MarketScope v5.9.11 — Table Stock / ETF Search

Added a dedicated **Search stock / ETF** field directly in Market Table controls.

- Filters **Table View only**; Card View is unchanged.
- Case-insensitive partial search.
- Searches Symbol, Name, Type, Sector, Industry, and Analyst Rating.
- Displays the current number of table matches while a search is active.
- Clearing the search restores the full currently-filtered Market Table.
