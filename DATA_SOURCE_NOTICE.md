# Data Source Notice

Primary market-data source: Yahoo Finance, accessed via the open-source `yfinance` Python library.

This application does not require a paid API subscription or API key. Data can be delayed, incomplete, corrected, rate-limited or temporarily unavailable. Historical calculations depend on the data returned by the provider.

The application is designed for personal informational/research use. Review Yahoo Finance/Yahoo terms and any applicable exchange licensing before redistributing market data, monetizing the application, or making it available as a public commercial service.
