# MarketScope 5.11.18

YTD and custom-date simulation summaries now reuse the existing Portfolio saved-card CSS classes, including the dark gradient, title font, small uppercase metric labels, white balances, separators, compact secondary metrics, and mobile breakpoints.

Positive profit/return and rebalance differences use the existing green class; negative values use red; zero uses the existing neutral class. None cadence retains a single Performance summary with no RB/NR labels. Existing saved records receive the new presentation when displayed. Calculations and stored values are unchanged.

Includes all v5.11.17 features. Preserve live data on deployment. Not deployed to Render by this release.
