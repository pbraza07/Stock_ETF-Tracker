# MarketScope v5.9.18

- Default Card View sort is now **1D performance, high to low**.
- Default Table View sort is now **1D performance, high to low**.
- Portfolio Split Simulator starts at **$100,000** on first load.
- Added visible **Nasdaq Universe Last Refreshed** status plus **Stocks Added / Removed Today** counts and symbols.
- The scheduled universe refresh compares the previous >$100B Nasdaq stock membership with the newly screened membership and stores the delta in snapshot metadata.
- Saved portfolio PDF page 1 now includes an instrument analyst snapshot with stock/ETF name, sector, analyst rating, target low, target average, and target high.
- Card View keeps the v5.9.7-style layout and retains clickable per-timeframe profit calculation for all short-horizon and 20 annual-return tiles.
