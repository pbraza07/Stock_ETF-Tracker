# v5.9.3 Fix / Feature Notes

- Added clickable period/year return tiles to every market card.
- Clicking 1D, 1M, 3M, 6M, YTD, or a calendar-year return calculates ending value and dollar profit for that exact period using the global investment amount.
- Added YTD as a standalone Investment Simulator horizon.
- Added a Portfolio Split Simulator with a default $200,000 total amount.
- Portfolio simulation supports multiple tracked stocks/ETFs, equal split or custom percentage allocation, and YTD or 1Y–10Y historical horizons.
- Portfolio results show total calculated ending value/profit plus per-instrument allocation, return, ending value, and profit.
- Missing history is identified and excluded rather than fabricated.
- Preserved card page, sort, primary filters, search, and investment settings when a period tile is selected.
- Added active-tile styling and mobile-readable selected-period and portfolio result panels.
